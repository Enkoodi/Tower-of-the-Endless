接线玩家攻击动画：让战斗中"玩家攻击"时，场景里的玩家本体和战斗界面头像同时播放攻击动画。改 3 个文件：

## 1. Assets/Animations/Player.controller（前置修复，否则动画慢半拍）
4 条转移（Idle→Attack、Idle→UI_Attack、Attack→Idle、UI_Attack→Idle）目前都开着 Has Exit Time（exit time 0.516129、transition duration 0.25）。直接编辑 YAML 文本，每条转移改为：
- `m_HasExitTime: 1` → `m_HasExitTime: 0`
- `m_ExitTime: 0.516129` → `m_ExitTime: 0`
- `m_TransitionDuration: 0.25` → `m_TransitionDuration: 0`（像素换帧动画不做交叉淡化，硬切避免闪帧）

效果：isAttack 参数一变化，状态立刻切换。提醒用户改完后让 Unity 重新加载资源（重新聚焦编辑器即可）。

## 2. Assets/Scripts/Battle/BattleUI.cs
新增公开方法 `SetPlayerAttackAnim(bool attacking)`：
- 懒解析：首次调用时若 playerAvatarAnimator 为空，则 `playerImage.GetComponent<Animator>()`（已确认 BattleCanvas.prefab 中 PlayerImage 对象上 Image 和 Animator 挂同一对象，controller 为 Player.controller）
- `playerAvatarAnimator.SetBool("isAttack", attacking)`，全程 null 保护
- 不改 BattleCanvas.prefab，避免手改预制体 YAML

## 3. Assets/Scripts/Core/BattleManager.cs
- 新增字段 `private Animator playerAnimator;`
- `StartBattle` 中：`playerAnimator = playerData?.GetComponent<Animator>();`（Player 与 PlayerData 同对象；普通撞敌战斗与 NpcBattler 对话战斗均走此入口，全路径覆盖）
- 新增私有 helper `SetPlayerAttackAnim(bool attacking)`：同时对场景玩家 Animator 和 `battleUI.SetPlayerAttackAnim(...)` 设值，带 null 保护
- `BattleCoroutine`：
  - 玩家攻击处（`enemy.TakeRawDamage` / 攻击日志行）调用 `SetPlayerAttackAnim(true)`
  - 该轮 `WaitForSeconds(logDelay)` 结束后（敌人反击前）调用 `SetPlayerAttackAnim(false)`
  - 伤害为 0 提前结束的分支（`damageToEnemy <= 0`）同样先设 true（EndBattle 会统一复位）
- `EndBattle` 开头调用 `SetPlayerAttackAnim(false)` 复位，覆盖所有结束路径

## 验证
Unity 运行 Game.unity：走向敌人触发战斗 → "玩家攻击"日志出现时，场景玩家与战斗界面头像立即播放攻击动画，敌人反击时回到 Idle；战斗速度调到最快时无卡状态；战斗结束（胜/败）后动画正常复位。
