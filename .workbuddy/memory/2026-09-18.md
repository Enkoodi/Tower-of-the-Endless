Canvas 下唯一容器 `Panel`（全屏拉伸，sprite=UISprite，alpha=1，是唯一可见底图）。

Panel 下的物体（全部挂 OpeningButton 的按钮，Image 一律 alpha=0 全透明）：
- `BattleSpeed`（锚点全拉伸，pos y=-400，sizeDelta -1000/-1300）= 居中横排容器
  - 子：`Text (TMP)`「战斗速度」字号64（x=-600）+ 4 个速度按钮
  - 按钮顺序与坐标：`Button`（-300，正常 1f）/ `Button (1)`（0，两倍 0.5f）
    / `Button (2)`（+300，四倍 0.25f）/ `Button (3)`（+600，跳过 0.01f）
- 底部一排：`NewGame`「新游戏」(-200,-625) / `Return`「返回游戏」(200,-625)
  / `Title`「回到标题」(600,-625) / `Exit`「退出游戏」(1000,-625)

### 关键实现机制（复用要点）
- **按钮零引用绑定**：SettingMenu.Awake 用 `GetComponentsInChildren<Button>(true)`
  按 **GameObject 名字** switch 绑定（Title/NewGame/Exit/Return）。
  新增按钮只需改名字 + 在 switch 加 case，不需要拖引用。
  ⚠️ 速度按钮也是按名字 `Button`/`Button (1) (2) (3)` 映射延迟值 —— 改名会静默退回 1f。
- **外框是代码画的**：OpeningButton.Awake 里 `CreateFrame()` 用 4 条无 sprite 的
  Image 细条（FrameTop/Bottom/Left/Right，thickness=6，raycastTarget=false）拼外框，
  纯色着色 + Lerp 过渡，不依赖任何图片资源/九宫格。
  默认 frameColor=(0.92,0.55,0.2) 橙，pressed=(1,0.85,0.6)，pressedScale=0.96，过渡速度14。
  `SetLocked(bool)` = 常驻选中框，用于互斥选择。实现 IPointerEnter/Exit/Down/Up + ISelect/Deselect。
- **战斗速度持久化**：选中 → `OpeningButton.SetLocked` + `BattleManager.Instance.LogDelay`
  + `SaveManager.SaveBattleSpeed(delay)`（写全局存档 battleSpeed）。
  进场景时 `SaveManager.LoadBattleSpeed()` 反查近似相等的按钮并 ApplySelection。
  跳过档 delay=0.01 会命中 `BattleManager.IsSkipMode`（logDelay<=阈值）→ 战斗只结算不开界面。
- **ESC 开关**：SettingsToggle 单例（RuntimeInitializeOnLoadMethod 自建 + DontDestroyOnLoad）。
  Opening/Game 按 ESC → 进 Setting（从 Game 进先 SaveAutoGame；时长 0.5s）；
  Setting 按 ESC → 回 previousSceneName。战斗窗口打开时（BattleManager.IsFighting）禁用 ESC。
  `ExitSettingsFromButton()` 给 Return 按钮用，等同 ESC。
- **场景跳转统一走 `ScreenFader.FadeToScene(name[,duration])`**（单例自建，
  sortingOrder=9999 遮罩，默认 fade 1s + 黑屏停留 1s）。
- StartNewGame：ClearAutoSave + LoadAutoSaveOnStart=false + FloorMemoryManager/SpecialEnemyManager ResetAll。
- QuitGame：先 SaveAutoGame，Editor 下停 Play。
- Canvas：ScreenSpaceOverlay(0)，CanvasScaler ScaleWithScreenSize，
  参考分辨率 **2560x1440**，matchWidthOrHeight=0（按宽度）。
- 全部 5 个场景已在 EditorBuildSettings 里 enabled（Opening/Game/Credits/Ending/Setting）。
